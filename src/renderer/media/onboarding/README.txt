Ролики для мастера первого запуска и обучения SoundPulse.

Формат: H.264 (MP4), 1600x904, 60 fps, AAC 48 кГц стерео.
Все ролики содержат звук — он воспроизводится вместе с видео.
Длительность 5-55 секунд.

Обучение (модуль 1: основы)
  tour-mic.mp4        - выбор микрофона
  tour-overlap.mp4    - наложение звуков
  tour-bass.mp4       - бас-эффект
  tour-fix-device.mp4 - если звук не слышно: выбрать устройство
  tour-mute.mp4       - кнопка Mute
  tour-selfmute.mp4   - свой микрофон
  tour-stop.mp4       - кнопка Стоп (F8)
  tour-test.mp4       - кнопка Тест
  tour-random.mp4     - режим Random
  tour-history.mp4    - история
  tour-modes.mp4      - режимы: динамики, микрофон, оба
  tour-close.mp4      - закрыть приложение
  tour-tray.mp4       - работа в трее

Обучение (модуль 2: библиотека)
  tour-add.mp4        - добавление звука, перетаскивание файлов
  tour-move.mp4       - перенос звука в другой набор
  tour-menu.mp4       - меню на карточке

Обучение (модуль 3: горячие клавиши)
  tour-wizard.mp4     - мастер настройки
  tour-vbcable.mp4    - виртуальный микрофон
  tour-hotkeys.mp4    - горячие клавиши

Все ролики показываются в блоке 16:9 через object-fit: cover, поэтому
чёрных полос нет. Файлы можно свободно заменять, сохраняя имена: приложение
ссылается на них по имени.
